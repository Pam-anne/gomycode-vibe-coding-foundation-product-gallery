# 🛍️ Product Showcase Gallery

## 📌 Project Overview
This project is a **responsive product showcase gallery** built using **HTML, CSS, and JavaScript only (no frameworks)**.

It features:
- A product grid layout
- Light and dark mode toggle
- Smooth animations
- Responsive design for different screen sizes

---

## 🎯 Objective
The goal of this checkpoint was to:
> Build a product gallery with hover effects, a theme toggle, and animations using only core web technologies.

---

## ✨ Features

### 🎨 UI & Layout
- Responsive grid layout using CSS Grid
- Clean and modern card design
- Organized and readable structure

### 🌙 Light/Dark Mode
- Toggle button to switch themes
- Theme state updates dynamically
- Different button color in dark mode

### 🎬 Animations
- Fade-in animation on page load
- Smooth hover effects on cards
- Button interaction animations (hover & click)

### 📱 Responsiveness
- Mobile-friendly layout
- Media queries for small, medium, and large screens

---

## 🛠️ Technologies Used
- **HTML5** → Structure
- **CSS3** → Styling, animations, responsiveness
- **JavaScript (Vanilla JS)** → Interactivity
